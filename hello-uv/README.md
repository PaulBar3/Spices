# Магазин товаров

Асинхронное веб-приложение для управления товарами с админ-панелью, построенное на современных технологиях Python.

## 🚀 Технологии

- **FastAPI** - современный асинхронный веб-фреймворк
- **SQLModel** - ORM для работы с базой данных (на основе SQLAlchemy и Pydantic)
- **SQLite + aiosqlite** - асинхронная база данных
- **Jinja2** - шаблонизатор для HTML
- **uv** - быстрый пакетный менеджер Python

## 🛠️ Установка и запуск

### Требования
- Python 3.11+
- uv (пакетный менеджер)

### Установка зависимостей

```bash
uv sync
```

### Запуск приложения

```bash
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Или используя скрипт из pyproject.toml:

```bash
uv run start
```

Приложение будет доступно по адресу: http://localhost:8000

## 📋 Функционал

### Публичная часть
- 📦 Просмотр каталога товаров
- 🔍 Детальная страница товара

### Админ панель (`/admin`)
- ➕ Создание новых товаров
- ✏️ Редактирование существующих товаров
- 🗑️ Удаление товаров
- 📊 Управление списком товаров

## 🔗 Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Главная страница (каталог товаров) |
| GET | `/product/{id}` | Детальная страница товара |
| GET | `/admin` | Админ панель |
| GET | `/admin/product/create` | Форма создания товара |
| POST | `/admin/product/create` | Создание товара |
| GET | `/admin/product/{id}/edit` | Форма редактирования товара |
| POST | `/admin/product/{id}/edit` | Обновление товара |
| POST | `/admin/product/{id}/delete` | Удаление товара |
| GET | `/health` | Проверка здоровья API |

## 💾 База данных

Приложение использует SQLite базу данных `products.db`, которая создается автоматически при первом запуске.

Модель товара включает:
- `id` - уникальный идентификатор
- `name` - название товара
- `description` - описание
- `price` - цена
- `image_url` - URL изображения (опционально)
- `created_at` - дата создания
- `updated_at` - дата обновления
